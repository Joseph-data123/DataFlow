# DataFlow

### Making Data Analysis Simple for Everyone

DataFlow is a beginner-friendly data analysis web application built using Python, Streamlit, Pandas, and Plotly.

The application allows users to upload, explore, clean, and visualize datasets without requiring programming or data analysis experience.

## Project Overview

DataFlow was developed to simplify common data analysis tasks by providing an interactive, easy-to-use interface.

Instead of writing Python code, users can perform cleaning operations, examine data quality, and generate visualizations through simple menus and buttons.

## Features

### 1. Data Upload
- Upload CSV datasets.
- Preview uploaded data.
- View the number of rows and columns.

### 2. Data Quality Assessment
- Identify missing values.
- Detect duplicate records.
- View missing values by column.
- Examine column data types.

### 3. Data Cleaning
- Standardize text capitalization.
- Remove unnecessary spaces.
- Remove duplicate records.
- Handle missing values using different cleaning methods.
- Preview changes before applying them.
- Apply multiple cleaning operations to the same dataset.

### 4. Data Visualization
- Generate interactive bar charts.
- Visualize trends over time using line charts.
- Select columns for visualization.

### 5. Data Export
- Download cleaned datasets as CSV files.

## Technologies Used

- Python: Application logic and data processing.
- Streamlit: Interactive web application interface.
- Pandas: Data manipulation, cleaning, and analysis.
- Plotly: Interactive data visualization.

## Project Status

DataFlow is currently a working prototype.

Future improvements may include a redesigned user interface, additional data validation, and more flexible visualization options.

## Project Goal

The goal of DataFlow is to make basic data analysis accessible to individuals who have little or no technical experience.

This project also demonstrates practical skills in Python programming, data cleaning, exploratory data analysis, and application development.
